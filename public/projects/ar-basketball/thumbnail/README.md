# Thumbnail Directory

คุณสามารถนำไฟล์วิดีโอ (เช่น `.mp4`) หรือไฟล์รูปภาพ (เช่น `.jpg`, `.png`) ตัวอย่างสั้นๆ มาวางในโฟลเดอร์นี้เพื่อใช้เป็นหน้าปกของการ์ดผลงาน:
- **ไม่ต้องฟิกซ์ชื่อไฟล์:** คุณสามารถตั้งชื่อไฟล์อะไรก็ได้ที่คุณต้องการ (เช่น `basketball_gameplay.mp4` หรือ `cover.jpg`)
- **การเชื่อมต่อกับเว็บ:** เมื่อวางไฟล์แล้ว กรุณาเข้าไปอัปเดตพาธไฟล์ให้ถูกต้องในไฟล์ `src/data/projects_data.json` ในฟิลด์ `media.thumbnail` (เช่น `"/projects/ar-basketball/thumbnail/ชื่อไฟล์ของคุณ.mp4"`)
- **สัดส่วนและแนวของวิดีโอ:**
  - **รองรับวิดีโอแนวตั้งอย่างสมบูรณ์แบบ:** หน้าเว็บได้รับการอัปเดตให้รองรับวิดีโอแนวตั้งแล้ว โดยจะเรนเดอร์แบบเต็มสัดส่วน (ไม่มีรอยแหว่งจากการครอปตัด) และตกแต่งพื้นหลังให้เคลื่อนไหวเบลออย่างหรูหราพรีเมียม
  - **รองรับภาพปกติ:** หากเลือกใช้ภาพปกติ จะแสดงผลสัดส่วนครอบคลุมหน้าการ์ดตามสไตล์ดั้งเดิม
